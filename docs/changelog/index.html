WALLPS / CHANGELOG

Changelog.

Every Wallps release, newest first. All builds are on GitHub Releases.

1.1.0 · 5 November 2026

  • Full redesign with native macOS controls and new type: Geist Serif for titles, Cove for everything else.
  • Previews that look like the real screens: a menu bar and Dock on the desktop, the live clock on the lock screen.
  • Swap button to flip the desktop and lock screen wallpapers.
  • Status line that shows whether your wallpapers are active, ready to apply, or paused.
  • Catalog sidebar grouped by macOS release and theme, with search and badges for what you're using.
  • New menu bar menu with wallpaper thumbnails, Swap, Browse and Pause Switching.
  • Universal build for Apple silicon and Intel.
  • Fixed: repairs a live lock screen that a macOS update removed.
  • Fixed: no longer blocks logout or shutdown while the catalog is open.
  • Fixed: desktop images stay sharp on Retina and 5K displays.

1.0.5 · 27 August 2026

  • Faster live wallpaper applies.
  • Drag a file onto either preview.

  • The catalog marks downloaded wallpapers.
  • Confirmation when a wallpaper is applied or downloaded.
  • Redesigned main window.

1.0.3 · 23 August 2026

  • Browse and download Apple's wallpapers inside Wallps.
  • Respects wallpapers picked in System Settings.
  • Faster image loading.

1.0.2 · 21 August 2026

  • Desktop images fill the whole display.
  • External displays recover their wallpaper after the lid wakes.
