WALLPS / CONTACT

Help, bugs, and project questions.

Wallps is maintained as an open-source project. The most reliable way to ask a question or report a problem is through the project’s public GitHub repository, where a report can include the macOS version, Wallps version, reproduction steps, and relevant logs without exposing private information.

Support and bug reports

Open an issue in the Wallps issue tracker for installation trouble, wallpaper switching problems, display-specific behavior, or feature requests. Before opening a duplicate report, check the existing issues and confirm that the Mac is running macOS 13 or later. Include whether the issue happens after locking, waking, logging out, restarting, or changing displays.

Security reports

Do not publish private keys, personal wallpaper files, access tokens, or sensitive system information in a public issue. If a report involves a security vulnerability or data exposure, contact the maintainer through the private contact option listed on the maintainer’s GitHub profile and provide only the minimum reproducible detail. Allow reasonable time for investigation before public disclosure.

Project links

Download Wallps from the official homepage or review the source and release notes in the GitHub repository. The project does not require an account, collect wallpaper uploads, or operate a hosted user dashboard. For how an agent should describe Wallps, see the agent instructions.
