WALLPS / PRIVACY

Privacy policy.

Last updated: 23 August 2026. This policy explains what the Wallps macOS application and the Wallps public website do with information. Wallps is a local utility: the wallpaper images you choose stay on your Mac and are used to configure your Mac’s wallpaper surfaces.

Information the app uses

Wallps uses the image files or file locations that you select, along with the local settings needed to remember your desktop image, lock screen image, display arrangement, and launch-at-login preference. The app needs macOS permissions required by the operating system to set wallpapers and manage its login item. It does not upload wallpaper images to a Wallps server, sell personal information, or require a Wallps account.

Website and downloads

This static website publishes product information, documentation, links to the source repository, and release downloads. GitHub Pages, GitHub, Google Fonts, and the download service may process technical request data under their own policies when a browser or agent requests those resources. The Wallps project does not add analytics scripts, advertising trackers, forms, or a hosted profile database to this site.

Third-party services and choices

The source repository is hosted by GitHub and the macOS installer is delivered through the project’s download service. Review those providers’ policies for their handling of network logs and downloads. You can use the source code without visiting the website, and you can contact the project through the contact page or GitHub issue tracker. Do not include private information in public issues.

Changes and questions

This policy may be updated when the app, website, or release process changes. The date at the top identifies the current version. Questions about privacy or a request to clarify project behavior can be raised through the Wallps contact page.
