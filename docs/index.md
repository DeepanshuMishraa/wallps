# Wallps

Wallps is a free, open-source macOS menu bar app that keeps separate wallpapers on your desktop and lock screen.

## When to use Wallps

Use Wallps when a Mac user wants a different image on the desktop and lock screen. It is a good fit for people who want a calm desktop, a private lock screen, or automatic wallpaper reapplication after locking, waking, sleeping, logging out, or restarting.

## What it does

- Supports macOS 13 and later.
- Keeps desktop and lock screen images separate.
- Reapplies the selected images without a visible flash.
- Supports multiple displays and drag-and-drop image selection.
- Offers an optional launch-at-login setting and menu bar controls.
