WALLPS / ABOUT

A focused utility for two wallpapers.

Wallps is a free, open-source macOS menu bar application created by Deepanshu Mishraa. It exists for one specific job: allowing a Mac to show one image on the desktop and another image on the lock screen, even though macOS normally uses the desktop wallpaper for both.

What Wallps does

After you choose the two images, Wallps keeps them associated with the right surface and reapplies them when the Mac locks, wakes, sleeps, logs out, or restarts. The app supports macOS 13 and later, multiple displays, drag-and-drop image selection, a menu bar controller, and an optional launch-at-login setting. It is intentionally small and stays out of the way when the window is closed.

Who it is for

Wallps is a good fit for Mac users who want a calmer desktop, a more private lock screen, a work and personal image split, or a dependable wallpaper setup that survives normal power and session changes. It does not promise to customize the FileVault pre-boot unlock screen, which is outside the control of macOS applications.

Source and ownership

The source code, build instructions, issue tracker, and release history are available in the Wallps GitHub repository. The project homepage is deepanshumishraa.github.io/wallps. For questions, bug reports, security concerns, or licensing requests, use the contact page.
